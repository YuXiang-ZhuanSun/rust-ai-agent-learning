核心模式

所有 Agent 都共享一个内核：把消息发给模型，执行模型请求的工具，把观察结果回填，然后循环直到模型停止。

agent_loop.rs
loop {
    let response = client.chat(&messages, &tools).await?;
    if response.tool_calls.is_none() {
        break response.text().to_string();
    }
    for call in response.tool_calls.unwrap() {
        let result = dispatch(&call.function.name, &call.function.arguments)?;
        messages.push(ChatMessage::tool(call.id, result));
    }
}
